LIL BOT MIAMI TEST LAB
======================

1. Extract the ZIP file.
2. Double-click index.html to open it in Chrome or Edge.
3. Use the expression buttons to preview each robot state.
4. Use Eye Construction to toggle between large inner pupils, bottom pools,
   organic crescents, small ovals, or Adaptive mode.
5. Move the mouse over the face, click it, and type on the keyboard.
6. Leave the page untouched for 20 seconds to test sleeping.

MICROPHONE RHYTHM TEST
Some browsers block microphone access for files opened directly from disk.
If that happens, open PowerShell inside this folder and run:

    py -m http.server 8080

Then visit this address in Chrome or Edge:

    http://localhost:8080

Click "Enable microphone rhythm test" and approve microphone access.

WHAT THIS TESTS
- Exact 320 x 170 face layout for the horizontal T-Display-S3
- Miami Vice cyan and hot-pink color design
- Dark, unlit pupil cutouts with no illuminated pupil or white reflection
- Toggleable eye constructions plus an Adaptive mood-based option
- Normal, happy, music, gaming, typing, sleepy, sleeping, surprised,
  annoyed, and overheating expressions
- Cursor tracking, click/touch reactions, keyboard reactions, and idle sleep
- Microphone-driven animation intensity

WHAT COMES NEXT
The browser cannot safely inspect Windows processes or system media sessions.
The Windows companion will detect those and send the same state names to the
physical ESP32 over USB. The visual state system in this lab is designed to
carry directly into that firmware.
